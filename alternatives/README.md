## Method and result

[HDJoJo's public dual-YOLO notebook](https://www.kaggle.com/code/hdjojo/solar-filament-segmentation) is the algorithm reference. The package independently implements its YOLO26x + YOLOv8x inference with one change: when only one model returns no masks, retain the other model's detections. Both absent still yields an empty image. The two descending sorts, mask NMS, confidence order, occupied-pixel subtraction before the minimum-area check, native resizing and gapped IDs are otherwise preserved. There are no semantic models or quality regressor in this alternative.

The fixed settings are input size 2048, confidence 0.5, box IoU 0, `max_det=100`, FP32, `retina_masks=False`, mask NMS IoU 0.5 and minimum area 5 pixels. The correction retained **8 masks on 7 images**; all 1,310 prior masks remained unchanged. The submitted output has **1,318 masks across 180 images** (178 nonempty), with zero overlapping output pixels. Its SHA-256 is `29911b4c87ae00a66bf0a21c2dee92e774078887d85bbac9ccbc86e3df5a984c`.

The full fresh local reproduction regenerated both models' predictions for all 180 images, independently audited native masks, and matched the final CSV exactly. Intermediate floating-point confidence equality was not required. This is a proof in the recorded existing local environment, not a fresh installation, cross-hardware guarantee, historical Kaggle-runtime reproduction, or local cross-validation result. The own-model fold scores in the main report do not validate these public checkpoints. The uploaders declare training on the 707 official TRAIN images; that declaration was not independently audited.
